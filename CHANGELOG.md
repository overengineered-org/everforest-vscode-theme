# Changelog

The canonical changelog is published as versioned GitHub Release notes.

- [Latest release](https://github.com/overengineered-org/everforest-vscode-theme/releases/latest)
- [All releases](https://github.com/overengineered-org/everforest-vscode-theme/releases)

## Versioning

Releases follow [Semantic Versioning](https://semver.org/):

- **MAJOR**: breaking changes.
- **MINOR**: new features.
- **PATCH**: bug fixes and other backward-compatible corrections.

Release notes are generated by semantic-release from Conventional Commits. `feat` commits appear as
Features and `fix` commits as Bug Fixes.

## Update policy

Published release notes are immutable records for their version. Changes are documented in the next
release rather than by maintaining duplicate manual entries in this file.
