## Version rules

- `fix:` → patch.
- `feat:` → minor.
- `feat!:` or `BREAKING CHANGE` → major.
- Documentation and chore-only changes → no release.

`release-it` generates release notes from Conventional Commits. Published notes remain immutable;
new corrections appear in the next release.
