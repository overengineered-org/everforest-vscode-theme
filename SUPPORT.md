# Support

Open the matching
[GitHub issue form](https://github.com/overengineered-org/everforest-vscode-theme/issues/new/choose).

Include these required details:

1. Exact Everforest Complete extension version.
2. Exact VS Code version.
3. Desktop, remote, or browser-hosted environment.
4. Light/Dark theme, contrast/workbench choices, and changed `everforestComplete.*` settings.
   Optionally include sanitised native `window.*`/`workbench.*` settings and workspace/folder
   override context.
5. Smallest reproduction steps and a sanitised screenshot or recording when visual.

Remove source code, workspace names, home paths, usernames, tokens, and other private data before
posting. For security vulnerabilities only, use the private
[GitHub Security Advisory](https://github.com/overengineered-org/everforest-vscode-theme/security/advisories/new)
intake; it is not a general support or conduct channel.
